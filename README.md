# Taskly
Taskly is a platform where teams can organize their plans and daily work, track issues, manage tasks. Its build as
production ready FastAPI backend system with strict clean architecture boundaries, and rich infrastructure

# Technology Stack

## Backend
- Python 3.13
- FastAPI
- SQLAlchemy 2.0 async + asyncpg
- Alembic
- Dishka
- Pydantic
- structlog
- OpenTelemetry

## Infrastructure
- Docker and Docker Compose
- Redis
- PostgreSQL
- Loki
- Alloy
- Grafana
- Mailpit
